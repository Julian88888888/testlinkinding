💡 Query Parameters: Ви можете змінити значення через URL параметри: ?title=...&desc=...&email=...&img=...
Примітка: Для того щоб LinkedIn бачив нові значення, потрібно оновити meta теги на сервері або використати серверний рендеринг.

📋 Інструкції

  • LinkedIn підтягує preview тільки з Open Graph мета-тегів - переконайтеся, що всі необхідні og:* теги присутні в <head> секції HTML.
  • Email як окреме поле - LinkedIn не підтримує окреме поле для email, тому ми вставляємо його в опис (og:description) або можемо додати на картинку.
  • Для повторного тесту - якщо LinkedIn показує старі дані, потрібно "пробити кеш" через LinkedIn Post Inspector. Цей інструмент дозволяє перевірити, які мета-теги бачить LinkedIn, та очистити кеш для конкретного URL.
  • Розмір зображення - рекомендований розмір для og:image: 1200x630 пікселів (співвідношення 1.91:1).
  • Абсолютні URL - всі URL (og:image, og:url) мають бути абсолютними (починатися з https://).
⚠️ Важливо: LinkedIn скрейпер читає HTML напряму з сервера. Якщо ви змінюєте meta теги через JavaScript, LinkedIn їх не побачить. Для динамічної зміни мета-тегів потрібен серверний рендеринг або статичні HTML файли з різними значеннями.
