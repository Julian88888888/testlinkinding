🖼️ Завантажити зображення на Imgur

Крок 1: Відкрийте https://imgur.com/upload
Крок 2: Перетягніть файл linkedin-share-image.jpg на сторінку або натисніть "New post" і виберіть файл
Крок 3: Після завантаження натисніть праву кнопку миші на зображенні → "Copy image address"
Крок 4: Оновіть HTML файли, замінивши URL в og:image на ваш Imgur URL
💡 Примітка: Imgur URL має виглядати так:
https://i.imgur.com/XXXXXXXX.jpg

Альтернатива: Налаштувати GitHub Pages

Якщо хочете використати GitHub Pages:
1. Відкрийте: Settings → Pages
2. Source: main branch, / (root) folder
3. Save
4. Зачекайте 1-5 хвилин
5. Зображення буде доступне за URL: https://julian88888888.github.io/testlinkinding/linkedin-share-image.jpg
